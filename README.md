# WISDOM
```
          _         _                 
__      _(_)___  __| | ___  _ __ ___  
\ \ /\ / / / __|/ _` |/ _ \| '_ ` _ \ 
 \ V  V /| \__ \ (_| | (_) | | | | | |
  \_/\_/ |_|___/\__,_|\___/|_| |_| |_|
```
A collection of quotes, shown at random at shell startup.

## Install

    git clone https://github.com/dropkick/wisdom ~/.config/quotes

Used by [dropkick/dotfiles](https://github.com/dropkick/dotfiles) — the
welcome script silently skips the quote if this repo isn't present.

## Update

    git -C ~/.config/quotes pull
